# Развёртывание PHP + MySQL

## Требования

- PHP 8.1 или новее с расширениями `pdo_mysql`, `session` и `openssl`.
- MySQL 8 / MariaDB 10.5 или новее.
- HTTPS. Без HTTPS админ-панель публиковать нельзя.
- Корень сайта должен указывать на этот каталог.

## 1. Создание таблиц

Импортируйте `database/schema.sql` в отдельную базу MySQL. Рабочему пользователю приложения выдайте только права:

```sql
GRANT SELECT, INSERT, UPDATE, DELETE ON database_name.* TO 'app_user'@'localhost';
```

Не выдавайте рабочему пользователю `DROP`, `ALTER`, `CREATE`, `FILE` или глобальные привилегии.

## 2. Секреты окружения

Настройте через панель хостинга или конфигурацию PHP-FPM/Apache следующие переменные окружения:

- `DB_HOST`
- `DB_PORT` — обычно `3306`
- `DB_NAME`
- `DB_USER`
- `DB_PASSWORD`
- `APP_SECRET` — случайная строка минимум 32 байта
- `ADMIN_USER` — логин администратора
- `ADMIN_PASSWORD_HASH` — хеш пароля, не сам пароль
- `ADMIN_ALLOWED_IPS` — необязательный список разрешённых IP через запятую; если задан, для остальных админка возвращает `404`
- `LEAD_RETENTION_DAYS` — срок хранения заявок, по умолчанию `1095` дней

Проект также умеет читать эти значения из файла `.env` в корне сайта. Скопируйте `.env.example` как `.env`, заполните его на сервере и установите права `600`. Файл `.env` исключён из Git и закрыт от HTTP-доступа правилами Apache.

Для локальной разработки без HTTPS можно временно задать `ALLOW_INSECURE_HTTP=1`. На боевом сервере этой переменной быть не должно.

Сгенерировать секрет и хеш на сервере:

```bash
php -r "echo bin2hex(random_bytes(32)), PHP_EOL;"
php -r "echo password_hash('ВВЕДИТЕ_ПАРОЛЬ_ЛОКАЛЬНО', PASSWORD_DEFAULT), PHP_EOL;"
```

Не добавляйте пароль, хеш, `APP_SECRET` или реквизиты MySQL в Git, HTML или JavaScript.

## 3. Telegram-уведомления

1. Создайте бота через `@BotFather` и получите токен.
2. Заполните в `.env`:

```dotenv
TELEGRAM_BOT_TOKEN=токен_от_BotFather
TELEGRAM_LOGIN=логин_для_бота
TELEGRAM_PASSWORD=пароль_для_бота
```

Адрес webhook и его защитный секрет настраиваются автоматически. Для регистрации webhook выполните из корня проекта:

```bash
php telegram/setup.php
```

После этого откройте личный чат с ботом, отправьте `/start`, затем введите логин и пароль. После успешного входа этот чат будет получать сообщение «Поступила новая заявка с сайта». Для подключения ещё одного получателя повторите вход с его Telegram-аккаунта.

Telegram требует публичный HTTPS-адрес webhook. Запросы защищены заголовком `X-Telegram-Bot-Api-Secret-Token`; webhook принимает только сообщения, а после ввода пароля бот пытается удалить сообщение с ним из чата.

## 4. Проверка

1. Откройте сайт по HTTPS и отправьте тестовую заявку.
2. Перейдите на `/admin/` и войдите с `ADMIN_USER` и исходным паролем.
3. Убедитесь, что заявка появилась, телефон открывает звонок, а статус меняется.
4. Проверьте, что `/server/` и `/database/schema.sql` возвращают `403`.
5. Отправьте ещё одну тестовую заявку и убедитесь, что авторизованный Telegram-чат получил уведомление.

## Nginx

Файлы `.htaccess` работают только в Apache/LiteSpeed. Для Nginx дополнительно запретите публичный доступ к `/server`, `/database`, скрытым и резервным файлам в конфигурации виртуального хоста.

Для страницы 404 в Nginx добавьте `error_page 404 /404.html;`.

## Резервные копии

Настройте ежедневный зашифрованный backup MySQL с ограниченным сроком хранения. Периодически проверяйте восстановление копии, а не только её создание.

## Удаление старых заявок

Добавьте ежедневный cron-запуск CLI-скрипта:

```bash
php /полный/путь/к/сайту/server/cleanup.php
```

Скрипт недоступен через браузер и удаляет заявки старше `LEAD_RETENTION_DAYS`.

## Подключение аналитики

Не вставляйте код Метрики или Google Analytics обычным `<script src>`, иначе он запустится до согласия. Подключайте отдельный локальный загрузчик так:

```html
<script type="text/plain" data-consent="analytics" data-src="/js/analytics.js" data-async></script>
```

`cookie-consent.js` активирует его только после выбора «Разрешить аналитику». До подключения Google Analytics отдельно проверьте требования к трансграничной передаче и уведомлению Роскомнадзора.
