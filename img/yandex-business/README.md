# Изображения услуг для Яндекс Бизнеса

Квадратные изображения 1254 × 1254 px в PNG. Текстовая зона занимает менее 20% площади; изображения не содержат цен, контактов, URL, логотипов, водяных знаков и элементов интерфейса Яндекса.

1. `01-lending.png` — Лендинг: одна страница для презентации услуги.
2. `02-chat-bot.png` — Чат-бот: автоматизация ответов и заявок.
3. `03-seo.png` — SEO-продвижение: развитие видимости сайта в поиске.
4. `04-online-store.png` — Интернет-магазин: каталог, корзина и онлайн-заказы.
5. `05-web-design.png` — Дизайн сайтов: интерфейс в фирменном стиле.
6. `06-multipage-site.png` — Многостраничный сайт: структура для услуг и контента.
